# 180 DAYS — Rebuild Yourself

Это первая PWA-версия трекера: тёмный интерфейс, 7 привычек, календарь на 180 дней, прогресс, серии, статистика, экспорт/импорт резервной копии.

## Как открыть на iPhone
Проект нужно разместить на HTTPS-хостинге (например, GitHub Pages). После публикации:
1. Откройте ссылку сайта в Safari.
2. Нажмите «Поделиться» → «На экран Домой».
3. Включите «Открывать как веб-приложение», если такой переключатель отображается.
4. Нажмите «Добавить».

## Важно
- Данные хранятся локально в браузере этого устройства. Очистка данных Safari может удалить их — регулярно делайте экспорт.
- Эта версия не синхронизируется автоматически с приложением «Команды».
- Команды можно настроить как ярлыки запуска и напоминания, но прямое чтение/запись данных PWA потребует отдельной интеграции.
- Это веб-приложение, а не нативное приложение App Store. Полноценный интерактивный виджет iOS потребует нативной оболочки/приложения; пока можно добавить иконку и ярлыки команд.
